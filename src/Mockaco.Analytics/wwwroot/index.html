How to read this atlas

Similarity, not identity

Profiles use HTTP method and URL-decoded, case-preserving paths. Numeric and GUID path segments become {id}; query values are excluded. Log-scaled request counts are TF-IDF weighted and normalized. Similar-source scores are cosine similarity on these full profiles. IP proximity, services, timing and request order do not contribute.

A projection, not a verdict

Centered PCA projects full profiles into two dimensions; the retained variance reports how much information survives. A shared fingerprint means the same normalized route/method set, not necessarily the same traffic mix. Separating overlaps adds small, deterministic offsets for readability. Confirm apparent neighbors with the full-profile scores.

What the matrix counts

Rows are transparent URL-based categories, not exploit classifications. Columns use recorded Nmap service names or Shodan modules, not port-based guesses. Blank banners are labeled unidentified by port. Search, request minimum and fingerprint selection define the matrix cohort; a cell selection highlights sources without narrowing its own denominator.

Capture boundaries

Request dates use the database clock; Before is exclusive. Nmap timestamps are job-update times. Shodan observation and retrieval times are shown separately in UTC. Service results can be older than the requests. Browsing and refresh read SQL; the explicit host cleanup action deletes selected hosts and linked records. Neither action triggers scans, replays requests, or contacts captured hosts.
